# ✈ Farematryx

**Smart Flight Fare Analytics & Booking Recommendation System**

A responsive web app that estimates flight ticket prices and recommends **Book Now / Wait**.

**Live demo:** https://YOUR-USERNAME.github.io/farematryx/

## Tech stack
HTML5, CSS3, JavaScript (frontend) · Python + scikit-learn (model training)

## Features
- Fare estimate from airline, route, class, stops, duration and days left
- Book Now / Wait recommendation
- Airline price comparison table and cards
- Dark mode, responsive layout, animated statistics

## Run locally
Open `index.html` in any browser. No installation needed.

## Note
Images in `/images` are placeholders. The fare formula is rule-based; a trained model is a planned upgrade.
